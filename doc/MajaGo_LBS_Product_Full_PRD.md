## 1. 背景与机会

### 1.1 行业现状
- 短视频平台强在内容消费，弱在本地深度关系与即时讨论。
- 本地社交需求旺盛，但传统社区产品缺乏内容引爆点与高频触达能力。
- 移动端用户在「内容发现 → 互动参与」之间存在明显断层。

### 1.2 机会窗口
- LBS 能天然形成“同城/同区”共同话题，适合形成持续群聊。
- 视频内容与群聊场景天然互补：内容引发话题，群聊沉淀关系。
- 轻度游戏社交可在群内形成更高频互动与留存。

---

## 2. 产品定位与核心价值

### 2.1 产品定位
面向本地用户的 LBS 短视频社群平台，将“短视频内容、群聊讨论、轻度游戏互动”整合为一体的日常社交体验。

### 2.2 核心价值
- 所见即所谈：视频与群聊即时联动，缩短从内容到社交的路径。
- 本地归属感：以城市/行政区为主线建立真实的本地社群氛围。
- 轻度游戏提升互动：游戏成为群聊的组织活动与留存手段。

### 2.3 差异化
- 评论区直接融合群聊入口，支持“视频评论/作者评论/位置群聊”三种话题维度。
- 自动入群 + LBS 群层级（AA1/AA2），降低社交门槛。
- Group 与 Game 的强联动：群聊为游戏引流，游戏反哺群聊活跃。

## 3. 产品目标

### 3.1 北极星指标
- 本地群聊日活跃用户（Local Group DAU）

### 3.2 核心目标
| 目标 | 指标定义 | 目标意义 |
| --- | --- | --- |
| 新用户成功入群 | 新用户完成定位授权且自动入群成功率 | 降低社交门槛 |
| 视频到群聊转化 | 打开评论区后进入位置群聊的比例 | 打通内容-社交路径 |
| 群活跃度 | 群内日均发言人数/发言条数 | 社群质量 |
| 游戏互动率 | Game 页触达后进入对局的比例 | 提升留存 |

### 3.3 非目标（本阶段不做）
- 电商交易闭环
- 复杂的游戏大厅与电竞赛事体系
- 强中心化的直播系统

## 4. 目标用户与核心场景

### 4.1 目标用户画像
1. 本地年轻用户（18-30）
   - 需求：发现附近热点、参与讨论、快速建立本地关系。
2. 本地内容创作者
   - 需求：内容获得更快讨论热度和转发扩散。
3. 轻度游戏用户
   - 需求：找人快速对局，群聊内维系互动。
4. 本地商家/社区运营者（中期）
   - 需求：运营本地社群、发起话题活动。

### 4.2 关键使用场景
- 看到了本地热点视频，立即加入本地群聊讨论。
- 新用户首次打开 App，自动进入城市官方群快速融入。
- 群聊中发起游戏对局，快速匹配附近玩家。
- 发布视频时自动同步到本地群，引发讨论。

## 5. 信息架构与页面结构

### 5.1 底部导航
- Home：短视频信息流
- Group：群聊入口与群管理（原 Explore）
- Upload：发布（带引导浮窗）
- Game：游戏中心（位于原 Inbox 位置）
- Mine：个人中心

### 5.2 关键页面结构
- Home: 视频流 + 评论弹层（视频/作者/位置）
- Group: 上方 Inbox 入口 + Nearby / My Groups 双页签
- Game: 游戏列表 + 快速匹配 + 升级中心入口 + 钱包入口
- Upload: 发布引导浮窗 → 选择 LBS → 拍摄/上传
- Mine: 账号信息、作品、资产与设置

## 6. 核心用户流程

### 6.1 新用户首次体验
注册/首次打开 → 定位授权 → 自动入群（本地官方群） → 浏览视频 → 评论区切换到位置群聊 → 进入群聊 → 参与讨论

### 6.2 视频消费到社交
浏览视频 → 进入评论区 → 选择“位置群聊” → 查看群聊卡片 → 加入/直接聊天 → 留存

### 6.3 发布流程
点击上传 → 发布引导浮窗（说明 LBS 同步机制） → 选择/确认位置 → 拍摄/上传 → 自动同步至本地群

### 6.4 游戏互动路径
进入 Game 页 → 快速匹配/选择游戏 → 房间列表 → 进入对局 → 结果结算 → 任务/升级中心领取奖励

## 7. 功能需求（按模块）

### 7.1 Home（短视频信息流）
- 顶部频道：Following / Nearby / Shorts / For You
- 内容混排：短视频 + 群聊卡片 + 游戏卡片
- 右侧操作：点赞、评论、收藏、分享
- 视频卡片展示位置标签，强调“同城可聊”

### 7.2 评论区融合
- 默认展示视频评论
- 支持切换：视频评论 / 作者评论 / 位置群聊
- 位置群聊使用“群聊卡片”形式展示，可直接加入/聊天
- 评论输入区支持快速发言

### 7.3 Group（群聊中心）
- 顶部保留 Inbox 入口（消息提醒点）
- 双页签：Nearby Groups / My Groups
- Nearby：显示当前行政区官方群（默认置顶）
- My Groups：显示用户已加入的群，支持快速进入聊天
- 群卡片显示：成员数、距离、活跃度、标签

### 7.4 Inbox（嵌入 Group）
- 作为 Group 页的右上角入口打开
- 展示最近聊天列表与系统通知
- 与群聊消息系统共用数据通道

### 7.5 Game（游戏中心）
- 顶部显示头像与币余额，支持进入钱包
- 升级中心入口（任务/成长体系）
- 快速匹配区：一键开始游戏
- 游戏列表：热门游戏 + 全部游戏
- 游戏房间列表：可进入房间、查看规则

### 7.6 游戏房间与对局
- 房间展示：人数、入场费、奖池、状态
- 进入房间后展示玩家准备状态
- 自动结算与战绩展示
- 对局结束后推送结果与奖励

### 7.7 钱包与资产
- 资产币种：Beans / Coins 等
- 充值、兑换、消费记录
- 交易流水可追溯

### 7.8 升级中心（任务系统）
- 日常任务 + 成就体系
- 任务进度实时更新
- 奖励领取与动效反馈

### 7.9 Upload（发布流程）
- 点击发布按钮弹出引导浮窗（非直接进相机）
- 引导内容包含：位置同步与群聊传播说明
- 必填 LBS 标签（城市/POI）
- 发布后自动同步到本地群聊

### 7.10 Mine（个人中心）
- 用户资料与作品展示
- 数据概览：粉丝、点赞、作品数
- 快捷入口：钱包、排行榜、设置

### 7.11 多语言与全球化
- App 内支持中英文切换
- Demo 可在屏幕外提供语言切换按钮
- 群聊与评论提供一键翻译能力（服务端支持）

## 8. UI/UX 设计原则

- 高对比度与强视觉层级，突出“内容与群聊入口”。
- 卡片化信息结构，群聊/游戏/内容统一视觉语法。
- 轻量动画：页面切换、弹层与引导浮窗具备明确反馈。
- 空状态引导：群聊/任务/钱包为空时提供清晰 CTA。

## 9. LBS 与社群逻辑

### 9.1 群层级
- AA1：省/州/城市级官方群（自动入群）
- AA2：区/街道/POI 群（推荐或搜索加入）

### 9.2 自动入群规则
- 新用户首次授权定位后自动加入 AA1 群
- 若不存在群则自动创建并指派默认管理员

### 9.3 进入群聊逻辑
- 已加入群：点击群卡片直接进入聊天
- 未加入群：点击加入，自动打开群聊

## 10. 服务端与系统架构

### 10.1 核心服务模块
- LBS Group Service：群创建与自动入群
- Content-Group Sync：视频发布后同步群卡片
- Comment Fusion Service：评论/群聊融合索引
- Group Discovery Service：附近群推荐
- Translation Service：群聊/评论翻译
- Notification Service：入群、评论、群消息推送
- Game Service：对局房间、匹配与结算
- Wallet Service：资产与交易流水

### 10.2 核心数据模型
- user: id, name, avatar, locale, location
- video: id, user_id, location, tags, create_time
- group: id, level, name, location, members
- membership: user_id, group_id, role
- comment: id, video_id, user_id, content
- message: id, group_id, user_id, content
- game_room: id, game_id, entry, players
- transaction: id, user_id, type, amount

### 10.3 关键流程（发布与同步）
1) 发布视频写入 video 表
2) MQ 异步触发内容同步
3) 根据 LBS 标签确定目标群
4) 同步群聊卡片到群消息流
5) 更新评论融合索引
6) 推送通知（可配置）

### 10.4 实时通信
- 群聊基于 WebSocket/MQTT
- 异步消息队列保障高并发写入

## 12. 运营策略

- 本地官方群运营：每日话题、活动公告、置顶消息
- 新人引导：入群欢迎语 + 新人任务
- 创作者激励：内容同步群聊提升曝光
- 游戏运营：每周赛事与奖励榜

---

## 13. 风险与合规

- 位置隐私：显式授权 + 可关闭定位
- 内容审核：短视频与群聊需双重审核
- 群聊安全：举报、拉黑、关键词过滤
- 账号安全：多因素与异常登录识别
