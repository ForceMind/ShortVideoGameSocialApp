# MajaGo LBS 短视频社群产品整合说明

版本：2026-01-26  
范围：APP 功能、UI/UX、服务端改造、产品说明

---

## 1. 产品说明（定位与价值主张）

**定位**：本地生活短视频社群。  
**核心价值**：所见即所得，所得即所聊。用户看到的 LBS 短视频可在对应本地群即时讨论与沉淀。  
**目标市场**：印度（重点）与东南亚（印尼/越南等），满足高移动渗透、强社交需求与本地化内容增长。

**解决的痛点**

- 短视频平台 LBS 侧重内容发现，缺乏深度社群沉淀。
- 传统本地社交缺乏短视频的高频传播能力。
- 新用户冷启动门槛高，难以快速进入社交关系网。

---

## 2. APP 核心功能（功能架构）

| 模块        | 核心能力                            | 关键价值          |
| --------- | ------------------------------- | ------------- |
| 自动 LBS 群组 | 注册/首次定位后自动加入省/邦/州群；冷启动自动创建群     | 降低社交门槛，形成归属感  |
| 内容-群组同步   | 短视频发布后自动同步卡片至本地群                | 内容分发 + 社群沉淀并行 |
| 评论区融合     | 视频评论与群聊讨论在评论区互通                 | 打通内容与社交路径     |
| 群组发现      | My Group / Nearby Group 分页 + 筛选 | 引导发现与多群管理     |
| LBS 标记与筛选 | 必填地理标记、支持街道/POI 级别              | 强化本地属性        |
| 多语言/翻译    | 群聊与评论支持一键翻译                     | 适配多语环境        |
| 本地运营能力    | 群公告、群主认证、内容激励                   | 活跃与内容质量保障     |

**用户核心流程（简版）**

1. 注册/首次打开：获取 IP + LBS 授权  
2. 系统自动入群：加入 AA1（省/邦/州）群，冷启动自动建群  
3. 浏览短视频：内容带地理标签  
4. 评论区融合：默认视频评论，可切换本地讨论  
5. 点击本地讨论：跳转 Group 群聊页  
6. 发布内容：强制 LBS 标记，自动同步到本地群

## 3. UI/UX 设计重点（关键界面）

**3.1 首页短视频 Feed**

- 顶部展示当前城市/区域与 LBS 状态
- 视频卡片显著显示地理标签与“同步到本地群”提示
- 右侧交互（赞/评/分享）与“进入群聊”入口

**3.2 评论区融合**

- 顶部双 Tab：视频评论 / 本地讨论  
- 本地讨论以“群聊卡片”展示，显示群名称、来源标签  
- “查看更多/进入群聊”作为自然导流按钮

**3.3 Group 页面**

- 新用户默认进入 LBS 自动群  
- 多群时切换为群列表：My Group / Nearby Group  
- 自动群默认置顶并标注“家乡群/官方本地群”

**3.4 新用户引导**

- 首次入群提示卡片/动效  
- LBS 授权清晰说明用途（为你连接本地社群）  

**3.5 发布页**

- 强制地理标记（街道/POI）  
- 发布前显示“同步到本地群”的提示

## 4. 服务端改造（系统与架构）

**4.1 新增/改造服务**

- LBS Group Service：AA1/AA2 群组划分、自动入群与建群  
- Content-Group Sync：短视频发布后同步群聊卡片  
- Comment Fusion Service：评论/群聊融合索引  
- Group Discovery Service：附近群推荐与筛选  
- Translation Service：多语言翻译能力  
- Notification Service：入群、同步、群公告推送

**4.2 数据模型与关联**

- `video` 与 `comment` 通过 `video_id` 关联  
- 群聊消息携带 `group_id`、`group_name`、`video_id`  
- 群组与地理层级（AA1/AA2）绑定，支持动态降级

**4.3 关键链路（发布与同步）**

1. 视频发布 → 写入 `video`  
2. 进入 MQ 异步任务  
3. 根据 LBS 标签确定群组  
4. 群组卡片同步至群聊流  
5. 评论区融合索引更新  
6. 推送通知（可选）

**4.4 高并发与弱网**

- MQ 异步队列处理同步与通知  
- ABR 视频自适应码率  
- 群聊采用 MQTT/WebSocket  
- 本地 CDN 与缓存节点，满足数据主权
