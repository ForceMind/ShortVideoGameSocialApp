# MajaGo UI 原型图详细说明文档

**版本：** V1.0 (UI Prototype)
**作者：** Manus AI
**日期：** 2026年1月26日

## 1. 原型图概览

本套原型图旨在展示 MajaGo 基于 LBS 的短视频与社群融合的核心交互流程。包含以下四个关键模块：

1.  **新用户引导 (Onboarding)**：LBS 授权及自动入群逻辑。
2.  **短视频播放与融合评论区 (Video & Comment)**：视频评论与本地讨论的无缝切换。
3.  **Group 列表页 (Group List)**：多群管理与地理位置群组置顶。
4.  **群聊详情页 (Group Chat)**：视频内容同步与本地社群互动。

---

## 2. 模块详细说明

### 2.1 新用户 LBS 授权与入群引导
*   **交互逻辑**：新用户注册后，系统触发 LBS 授权请求。授权成功后，系统根据地理位置自动将其加入对应的“邦/省/州”群聊。
*   **视觉重点**：如果用户是该区域首位成员，展示“第一位成员”荣誉勋章，激发用户拉新动力。
*   **图示参考**：见 `majago_onboarding_ui.png`。

### 2.2 短视频播放页与融合评论区
*   **交互逻辑**：
    *   用户点击视频评论图标，弹出评论抽屉。
    *   抽屉顶部设有 **Standard Comments**（普通评论）和 **Local Group Discussion**（本地群聊讨论）两个页签。
    *   **本地讨论页签**：展示来自对应地理位置群组的实时对话。点击讨论卡片中的“Join Group”或“View More”，直接跳转至 Group 详情页。
*   **图示参考**：见 `majago_video_comment_ui.png`。

### 2.3 Group 社交页 (多模式)
*   **单群模式**：对于新用户或仅加入一个群的用户，点击 Group Tab 直接进入群聊详情，缩短交互路径。
*   **列表模式**：当用户加入多个群后，展示群组列表。
    *   **置顶逻辑**：系统自动分配的 LBS 群组默认置顶，并有特殊背景色区分。
    *   **页签切换**：顶部支持“My Groups”和“Nearby Groups”切换，方便发现周边兴趣社群。
*   **图示参考**：见 `majago_group_ui.png`。

### 2.4 群聊详情与内容同步
*   **交互逻辑**：地理位置相关的短视频会自动以“视频卡片”形式同步至群聊。群内成员可直接点击观看并参与讨论。
*   **图示参考**：见 `majago_group_ui.png` 中的 `Group_Chat_View`。

## 3. 设计规范建议 (给 UI 设计师)

*   **色彩体系**：建议使用高饱和度的品牌色（如 MajaGo 蓝/绿）作为操作指引色，本地社群相关内容可使用温和的辅助色（如浅黄或浅绿）进行背景区分。
*   **适配性**：考虑到印度及东南亚市场存在大量低端安卓机型，评论抽屉的弹出动效需保持流畅，避免过多的模糊（Blur）和阴影（Shadow）计算。
*   **多语言布局**：UI 需预留足够的字符空间，以适配印地语、印尼语等字符较长的语言。
